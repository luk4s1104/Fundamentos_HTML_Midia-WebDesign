# Mídias, Estruturas e Versionamento (WebDesign - FACENS)

Este projeto foi feito para a aula de WebDesign na FACENS. O objetivo principal foi aprender a colocar mídias (imagens, vídeos e áudios) rodando direto no HTML, organizar a página usando tabelas e contêineres (`<div>`), e entender de vez como usar IDs e Classes no CSS para estilizar tudo.

---

## O que foi feito no projeto:

*   **Mídias bem organizadas:** Em vez de jogar tudo solto, separei os arquivos em pastas específicas (`Audio`, `Imagens` e `Video`) e linkei no HTML usando caminhos relativos.
*   **Tags de Áudio e Vídeo:** Usei os controles nativos do navegador (`controls`) e adicionei imagem de capa (`poster`) nos vídeos.
*   **IDs e Classes no CSS:** Apliquei IDs para elementos únicos (como o `#introducao`) e criei a classe `.destaque` com fundo colorido para reaproveitar o estilo em mais de um parágrafo.
*   **Uso de Divs:** Agrupei subtítulos e textos dentro de tags `<div>` para criar blocos organizados de conteúdo.
*   **Versionamento com Git:** Todo o progresso foi salvo passo a passo usando commits reais pelo Source Control do VS Code, registrando o histórico de evolução do código direto aqui no GitHub.
